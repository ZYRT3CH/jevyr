# Jevyr launch thread

This is the eight-post thread used to introduce Jevyr on X. It is kept here so
the project has a stable, readable copy of the explanation that first brought
people to the repository.

The thread mentions Jev only to explain the timing. Jevyr is an independent
open-source project with no technical relationship to Jev.

## The thread

### 1/8 — the question

[View the post on X](https://x.com/Zyrt3C/status/2100687868523938269)

> What if an AI answer had to earn trust?
>
> I'm open-sourcing [#Jevyr](https://x.com/hashtag/Jevyr?src=hashtag_click), pronounced Jev-yr. I started building it in early 2026. I've been 5 years working fulltime in the AI Space. The timing is funny because [#Jev](https://x.com/hashtag/Jev?src=hashtag_click) is now getting attention too. (Sloppy video for exposure lol)

### 2/8 — not a chat buddy

[View the post on X](https://x.com/Zyrt3C/status/2100687871090761927)

> Jev and Jevyr overlap in one broad idea: neither is designed to be a chat buddy.
>
> Jev returns structured decisions instead of conversational replies. Jevyr is an open-source system around models. No technical relationship.

### 3/8 — proposals and tests

[View the post on X](https://x.com/Zyrt3C/status/2100687874186199276)

> In Jevyr, models propose explanations, solutions, code, plans, or tests.
>
> Jevyr compares candidates, runs bounded experiments, preserves evidence, and returns:
>
> Accepted. Rejected. Unproven.

![A concrete parser Case in the Jevyr Chamber](../screenshots/chamber-parser-specimen.png)

### 4/8 — not a truth machine

[View the post on X](https://x.com/Zyrt3C/status/2100687877034160471)

> It is not a chatbot or truth machine.
>
> It is an experiment in separating generation from judgment:
>
> Models may make claims. Evidence must decide whether they hold up.

### 5/8 — built for agents

[View the post on X](https://x.com/Zyrt3C/status/2100687879919816715)

> Jevyr includes a local MCP server so other AI agents can use it.
>
> A Case is finite and replayable, not an endless conversation. The Chamber is an optional human window into what happened.

![The Jevyr Inspect view](../screenshots/chamber-inspect.png)

### 6/8 — possible uses

[View the post on X](https://x.com/Zyrt3C/status/2100687884239950188)

> You can use it to review code and designs, test tool actions, compare models, audit claims against files, or decide whether AI-generated memory deserves to be reused.

![The human-readable Jevyr Couch view](../screenshots/chamber-couch.png)

### 7/8 — where it could go

[View the post on X](https://x.com/Zyrt3C/status/2100687886978892224)

> It can also support simulation-first robotics and research into multi-agent reasoning, disagreement, uncertainty, reproducibility, and model evaluation. Physical hardware needs its own adapter and safety boundary.

### 8/8 — an open invitation

[View the post on X](https://x.com/Zyrt3C/status/2100687889063416272)

> After five years in AI, this is my first open-source project.
>
> It is unfinished and complex, but I'm sharing it to inspect, fork, experiment with, and turn into something new.

## Visual order

The first post carries the launch video. For the remaining thread, the images are
intentionally spaced out:

1. Post 3 — parser specimen: a concrete example of proposals, execution, and evidence.
2. Post 5 — Inspect view: the MCP-facing Case, phases, ledger, and measured work.
3. Post 6 — Couch view: the optional human window for reading what happened.

Three images are enough to give the thread a visual rhythm without making it
feel like a product catalogue.
