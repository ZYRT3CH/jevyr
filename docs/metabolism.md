# Live metabolic additions

Juggler admits an offered opaque ball identity and an integer quantity. `POST /runs/:id/metabolism` accepts exactly `{ "ballId": "ball_…", "quantity": 1 }`. The corresponding GET publishes calibrated offers, their cost ceilings, current context availability, cumulative quantities, and the signed receipt history. Sovereign has no metabolic admission channel. Legacy checkpoint vouchers are disabled for new runs.

The original Search Envelope is the baseline. A separate `policy.metabolicAllowance` is bound before Cast and limits all additions together. Its maximum added totals are at most one additional baseline allocation; each unit grants one Mind invocation and a proportional share of metered totals. Per-invocation timeout, network permission, concurrent lineage ceiling, capabilities, obligations, Bone, and Genome are immutable. An offered quantity is additionally limited by the largest measured dose, cumulative prior doses, remaining total allowance, and currently available work.

The five units have concrete scheduler effects: Mass adds a general investigation, Refraction explores distinct unused presealed experiment templates, Polarity challenges a committed hypothesis, Fission runs an isolated lane before sharing its output, and Inertia lowers the continuation threshold after physical assay observations. Refraction's measured template diversity does not establish conceptual independence.

Inertia uses an explicit heuristic: critical signal divided by the number of observed attempts plus one, then divided by the presealed assay cost. Its baseline threshold is 0.5; cumulative dose `q` lowers that threshold to `0.5 / (1 + q)`. Only distinct, unresolved candidates below the original threshold and above the new threshold are selectable. Blocked executions, resolved passing obligations, duplicated observations, and work already selected do not fabricate new eligibility. Each decision binds its signed dose, actual observation digests, history, and selected candidates. This is a finite scheduling estimate, not a learned probability or verdict authority. Nursery saturation alone cannot expose Inertia.

Each accepted addition receives a sequenced Ed25519 DSSE receipt under a separate key whose public identity is sealed in the allowance. Bone persists the receipt, exports its signed wrapper, and records `metabolism.grant` before the scheduler can use it. `metabolism.admitted` marks the exact ledger prefix where its resources become spendable. Replay verifies both the chain and admission order. The ordinary three Seal, Record, and terminal signing authorizations are unchanged.

The scheduler preserves baseline calls and schedules the additional queue separately. The channel remains live until work admission closes. Closing waits for accepted writes and drains their final committed work. Contextually unavailable work receives an explicit unfulfilled annotation; no other effect is substituted. A signing or publication failure admits no work.

## Calibration evidence

Startup reads `.jevyr/metabolic-calibrations/Mass.json` and corresponding files for other kinds, with raw observations in `artifacts/<sha256hex>.json` beneath that directory. Missing calibration disables the kind. Malformed reports, substituted bytes, or a changed measured implementation fail startup. The allowance binds the complete report digest, the offered summary digest, and the measured maximum dose. A cost ceiling below the measured per-unit maximum suppresses that offer.

Calibration requires at least 64 complete paired seeds at contiguous doses starting with 0, 1, and 2. It independently checks preserved baseline traces, exact monotonic additions, distinct Refraction templates and Fission lanes, identical fixed-evidence kernel verdicts, and repeated traces and defect outcomes. The verifier computes conservative Wilson 95% difference intervals from actual counts. Each seed is one statistical unit; four correlated mutations cannot count as four independent samples. The declared noninferiority margin cannot exceed 0.1. These count-based intervals rely on binomial sampling assumptions. Systematic deterministic fixtures are not a random population sample, so their endpoints are diagnostic bounds, not empirical confidence in live-model performance.

Run the finite experiment after building the packages:

```powershell
pnpm build
node apps/cli/node_modules/tsx/dist/cli.mjs scripts/calibrate-metabolism.ts --output artifacts/metabolic-calibration
node benchmarks/verify-metabolic-calibration.mjs artifacts/metabolic-calibration
node apps/cli/node_modules/tsx/dist/cli.mjs scripts/metabolic-lifecycle-proof.ts artifacts/metabolic-calibration
node scripts/install-metabolic-calibration.mjs artifacts/metabolic-calibration
```

Installation captures a bounded snapshot before checking the reports, reserves a fresh destination, and copies only those captured bytes. It independently verifies the raw observations again in that destination, compares every copied file with the checked snapshot, and writes `installation.json` last. It refuses an existing destination rather than merging files. A failed installation leaves an unpublished directory for inspection. The command's optional second argument chooses a fresh destination; an alternate path remains prepared evidence until placed at the project's `.jevyr/metabolic-calibrations` path. Preserve an existing calibration directory separately before replacing it. The daemon reads the canonical path at its next startup.

The experiment uses actual scheduler calls, runs generated Node and Python fixture probes, executes four planted mutation checks, and recomputes a formal fixed-evidence kernel verdict. Inertia runs the same revision-request constructor, metered invocation, and parent-bound admission helper as production after actual failing host probes. Its independent verifier replays the baseline and added scheduler calls, reconstructs exact conservative token and generated-byte usage, and binds each failing probe to its own admitted parent source. A separate bounded local monotonic-clock receipt records wall time; that clock reading is unsigned and cannot be independently reproduced or remotely attested. The verifier reconstructs the revision request and committed parent source, reruns only trusted local fixture source, compares captured outputs and artifact hashes, and validates trace and evidence links. It never executes arbitrary code supplied by a report. Forge execution has separate signed lifecycle proofs. Diagnostic runs with fewer than 64 seeds intentionally cannot authorize exposure; `--diagnostic` verification writes a separate result with `valid: false`.

These are unsigned local, finite-fixture measurements. They establish the stated scheduler behavior and fixture regression bounds. They do not establish live-model efficacy, conceptual independence of test families, or defect recall outside the measured corpus. Those claims require additional representative experiments; fixture reports must retain their explicit scope when shown in offers or release evidence.
