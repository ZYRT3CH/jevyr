## Still proposed: explicitly measure the native GPT profile

Ollama documents `tools`, `tool_choice` and `response_format` for its compatibility endpoint. Its tool-calling examples declare function names and route returned calls to matching functions. These documents support trying the native route; they do not establish that this installed model/server combination obeys every combined schema. See [compatibility fields](https://docs.ollama.com/api/openai-compatibility) and [tool-calling contract](https://docs.ollama.com/capabilities/tool-calling).

Predeclare a separate compatibility attempt with `investigationTransport: "native"` (configuration equivalent: `JEVYR_OLLAMA_INVESTIGATION_TRANSPORT=native`). Use the same public fixture, model digest and bounds, with no hidden fallback. The [existing native encoder](../packages/runtime/src/adapters/openai-compatible.ts) advertises exact authorized functions during inspection, retains the stage-owned structured response schema, and removes callable tools on the final round. A protocol name must never be silently unwrapped into an authorized function; receipt and argument validation remain mandatory.

Before live execution, test that exact advertised calls can inspect source, undeclared names and mixed channels fail safely, incomplete inspection cannot finalize, and the final request offers no functions. The shared loop currently recognizes native response calls even when the selected request transport is structured; an explicit channel-mismatch failure would clarify that profile's promise without granting new tools. Decide that behavior separately before changing a method identity.

A subsequent native-profile lifecycle cohort must be declared as a **changed profile**, retain every attempt and the unchanged strict gates, and report recovery separately. If any method also changes, record both changes; do not attribute a difference to transport alone. The post-diagnostic native-profile proposal has not been executed. This documentation refresh made no runtime changes, builds or additional model calls.
