# Jevyr documentation

**Jevyr** is the public name. The lower-case `jevyr` command, package names, stores, and wire identifiers are the canonical technical names; the spelling is not a claim of trademark availability.

Jevyr accepts one sealed impulse, creates and challenges possible responses, embodies what it can in a disposable Forge, compiles a verdict from admissible evidence, signs a Record, and ends. A human may observe the public trace in real time but cannot steer the active case after sealing.
