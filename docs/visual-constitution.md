# Chamber visual constitution

The Chamber is a human-readable projection of Blood. It is not Jevyr itself, and it has no authority over a running Case.

Its trust vocabulary is literal. Live events are accepted only through the SDK's exact schema, cursor, prior-digest, case/run, forward-stage, and recomputed-content checks. The Chamber labels the Seal “verified” only after browser-side Ed25519 verification against the advertised public-key bundle. After the terminal event arrests motion, it calls the SDK's full authenticated-terminal path and labels the closure “authenticated” only when the Record and separate terminal receipt verify under the same key, the Record binds the accepted case, run, IntentContract, and a crystallization head present in the visible ledger, and the receipt binds the exact final ledger and status projection, canonical Record digest, and complete artifact-index digest. A terminal event alone is not proof. The anatomy specimen is permanently labelled unclaimed.

## What the human must be able to know

At any live moment, the Chamber must make these questions answerable:

1. What changed since the last accepted event?
2. Which claim, candidate, action, or assay changed state?
3. What evidence caused that change, and what is its authority?
4. Where is work blocked, and is the block epistemic, physical, or infrastructural?
5. Which lineages were discarded, scarred, or retained as incompatible alternatives?
6. How much sealed effort remains, and is novelty still arriving?
7. Is the cursor and digest chain continuous?
8. Has the Case terminated, and what does the signed Record actually bind?
9. Has the separate terminal receipt authenticated the exact final head, status projection, Record, and artifact inventory—or has motion merely stopped?

Watching must never become steering. There are no approval controls, preference reactions, retry-with-feedback affordances, or concealed continuation channels.

## Rejected visual grammar

Jevyr must not converge on:

- game HUDs, tactical maps, neon node graphs, mission-control chrome, or scoreboards;
- cream editorial wallpaper, ornamental topology, ambient blobs, or “organic” motion unrelated to real events;
- default component-library composition, generic AI gradients, glass cards, pill badges, and dashboard furniture;
- decoration that changes while the underlying case state does not;
- spectacular motion that cannot explain what caused it.

## Implemented causal grammar

The renderer consumes the deterministic Chamber morphology read model, never raw event count or lifecycle progress as an aesthetic score.

| Public fact | Material consequence |
| --- | --- |
| Candidate status | Thin proposal sac, bone selection incision, dense embodiment, chalk survival edge, or collapsed vermilion wound |
| Declared parent IDs and lineage roots | Stable glass capillaries with locally moving menisci; undisclosed or external roots remain broken-lined |
| Evidence relation and authority | Directed needles whose solidity comes from evidence class; refutation is a wound color; unlinked evidence remains an ampoule |
| Requirement and assay state | Tendons stay taut while unresolved, break or discolor on failure, and settle only after resolution |
| Measured physical resources | An asymmetric pressure membrane constricts; declared-only resources remain an unclosed dry bracket; overruns rupture |
| Candidate and assay failure | Attributed cuts remain at the failed subject; aggregate nursery scars remain an anonymous bruise |
| Exact hypothesis yield | Local buds age as exact yield stalls, without being called semantic novelty |
| Measured assay archive | A separate refractive structure records admitted novelty and never substitutes for exact-content yield |
| Digest continuity | Broken continuity shears the anatomy instead of smoothing through the gap |
| Completed terminal stage event | A fused seam appears and all motion arrests at a deterministic phase; the seam alone is not signature proof |

Motion is event-driven and local. Focusing an event opens a temporal microscope: the Chamber reconstructs the deterministic morphology of the exact accepted Blood prefix at that sequence and names both the projected cursor and the still-advancing live cursor. This changes only the observer's projection; polling, execution, evidence, and the Case remain untouched. Returning to current Blood discards the historical projection. With no candidates, the Chamber shows only the sealed incision plus any real obligations or evidence—it does not invent an organism from stage announcements.

The Chamber's production surface is hand-built canvas, React, and raw CSS. It does not ship a component-library vocabulary or a Tailwind/shadcn theme layer. This is an implementation constraint, not an aesthetic claim: causal legibility still has to be proven in use.

An explicit `?specimen=1` mode may demonstrate anatomy without a daemon, but it must remain labelled as non-execution. A failed real Cast must never silently become a specimen.
